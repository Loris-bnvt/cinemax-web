# Cinémax pour iPhone

Version web de l'app Cinémax, à ouvrir dans Safari puis **Partager → Sur l'écran d'accueil**.

Adresse : http://cinemaxbylolo.duckdns.org (en http : le serveur IPTV est en http).

Ce dépôt est rempli automatiquement à partir de la branche `version-iphone-web` du dépôt Cinémax
(`node scripts/iphone-web-build.mjs`). Ne pas modifier les fichiers à la main.
